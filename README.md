# CASP15 FM: AlphaFold2 (ColabFold) vs ESMFold

CMP_SC 8170, Project 3 (Prof. Jianlin Cheng). Nancy Ihechu.

Compares AlphaFold2 (ColabFold, `alphafold2_ptm`, with an MSA, templates off) and
ESMFold (single sequence) on 6 CASP15 free-modeling targets:
T1104, T1122, T1159, T1187, T1194, T1113.

Questions:
1. At what MSA depth does AlphaFold2 drop to ESMFold's accuracy?
2. Does ESM-2 pseudo-perplexity predict which targets are hard?
3. Accuracy vs speed: how much do we lose with ESMFold, and how much time do we save?

Status: work in progress. How to rerun, results, figures and limitations will be added here.
